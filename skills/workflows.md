# 工作流和自动化

可复用的工作流程、自动化脚本和最佳实践。

## 工作流分类

### 知识管理工作流

#### 日常记录流程

1. 创建 `/daily/YYYY-MM-DD.md`
2. 记录当天的想法、发现、实验
3. 定期审查和整理
4. 将重要内容提升到长期记忆

#### 工具添加流程

1. 发现新工具
2. 在 `/daily/` 记录初步信息
3. 测试工具的实用性
4. 添加到 `/tools/ai-tools.md`
5. 在 `/memory/` 创建详细文档（如需要）

#### 项目启动流程

1. 在 `/projects/ideas.md` 记录想法
2. 收集相关资源和参考
3. 创建项目计划文件 `/projects/PROJECT_NAME.md`
4. 跟踪进展和学习
