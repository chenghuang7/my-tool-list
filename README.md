# AI 工作空间 & 知识系统

这是一个持久化的 AI 工作空间和长期知识系统。

## 核心原则

- **文件是真实来源** - 不依赖临时对话记忆
- **知识永久保存** - 重要信息必须写入文件
- **简实用** - 简单、实用、可扩展
- **轻量级** - 优先 markdown，而非复杂数据库
- **模块化** - 小型可组合结构

## 目录结构

```
├── /memory          # 长期知识库 - 稳定、重要的信息
├── /skills          # 可复用的 AI 技能和提示词
├── /tools           # AI 工具和服务汇总
├── /projects        # 个人项目和想法
├── /notes           # 学习笔记和文档
├── /daily           # 日常记录（临时）
├── /scratch         # 实验和草稿
└── README.md        # 系统文档
```

## 使用指南

### 添加新工具
1. 编辑 `/tools/ai-tools.md`
2. 按类别和难度分类
3. 记录：名称、链接、描述、可部署性、标签

### 记录新想法
1. 先写入 `/daily/` 或 `/scratch/`
2. 整理后提升到 `/memory/` 或 `/projects/`

### 保存重要知识
1. 在对话中发现重要信息
2. 立即写入相关的 `.md` 文件
3. 添加文件链接到 INDEX
